# CAD 文字工具集：MT2CSV + FONTFIX

这是两个给 AutoCAD 用的小工具，解决两个很常见的麻烦：

- **MT2CSV**：把 CAD 图里的文字抄出来，保存成 Excel 能打开的 CSV 文件。
- **FONTFIX**：图纸里的文字变成问号、字体混乱时，批量把文字改成统一的字体样式。

简单说，MT2CSV 负责“把字拿出来”，FONTFIX 负责“把字修正常”。

## MT2CSV 功能

MT2CSV 可以读取 CAD 中的单行文字和多行文字（`TEXT` / `MTEXT`），并自动清理 CAD 文字里的格式代码，例如字号、颜色、换行等标记，只保留真正看到的文字内容。

它有两种整理顺序：

1. **选择顺序**：你点文字的先后顺序，就是 CSV 里的先后顺序。适合按业务顺序、编号顺序提取。
2. **XY 坐标顺序**：按照图纸上的位置，从上到下、从左到右整理。适合表格、清单或排版整齐的文字。

导出的文件会自动保存到桌面，文件名中带有导出时间，避免反复导出时互相覆盖。生成的 CSV 可以直接用 Excel 打开。

## MT2CSV 使用方法

1. 打开 AutoCAD，输入 `APPLOAD` 并回车。
2. 找到并加载 `plugins/mt2csv/MT2CSV-V4.lsp`。
3. 在命令行输入 `MT2CSV` 并回车。
4. 选择排序方式：直接回车使用默认方式，或输入 `XY` 使用坐标排序。
5. 选择要提取的文字，选完后按回车。
6. 到桌面找到自动生成的 CSV 文件，用 Excel 打开即可。

如果只是想按自己点击的顺序导出，就使用选择顺序；如果想让图纸上的文字按位置排好，就使用 XY 排序。

支持帖子所述的 AutoCAD 2000–2026（实际兼容性以本机版本测试为准）。

## FONTFIX 功能与使用方法

`plugins/fontfix/FONTFIX.LSP` 是配套的字体修复工具。它会把选中的文字，或整张图里的文字，统一改成 `STANDARD` 文字样式，并清理部分可能导致显示异常的附加信息。

它有两种模式：

- **A：全图处理**：自动处理当前图纸中的所有 TEXT/MTEXT。
- **S：手动选择**：只处理你框选或点选的文字。

使用步骤：

1. 在 AutoCAD 中用 `APPLOAD` 加载 `plugins/fontfix/FONTFIX.LSP`。
2. 输入 `FONTFIX` 并回车。
3. 输入 `A` 处理整张图，或输入 `S` 只处理选中的文字。
4. 按命令行提示完成操作。

使用 FONTFIX 前建议先保存图纸，并最好在副本上试用，因为它会直接修改文字样式。
